# 代码质量度量标准

## 1. 代码复杂度指标

### 1.1 圈复杂度（Cyclomatic Complexity）
- **目标**: 每个函数 ≤ 10
- **警告**: 10-15
- **严重**: > 15

计算公式：`M = E - N + 2P`
- E = 边数
- N = 节点数
- P = 连通分量数

### 1.2 认知复杂度
- **目标**: 每个函数 ≤ 15
- **警告**: 15-20
- **严重**: > 20

### 1.3 函数长度
- **目标**: 每函数 ≤ 50 行
- **警告**: 50-80 行
- **严重**: > 80 行

### 1.4 参数数量
- **目标**: 每函数 ≤ 5 个参数
- **警告**: 5-7 个
- **严重**: > 7 个

## 2. 代码重复指标

### 2.1 重复代码率
- **目标**: < 3%
- **警告**: 3-5%
- **严重**: > 5%

### 2.2 重复块大小
- **目标**: 无重复代码块 > 10 行
- **警告**: 重复代码块 10-20 行
- **严重**: 重复代码块 > 20 行

## 3. 测试覆盖指标

### 3.1 行覆盖率
- **目标**: ≥ 80%
- **警告**: 60-80%
- **严重**: < 60%

### 3.2 分支覆盖率
- **目标**: ≥ 75%
- **警告**: 50-75%
- **严重**: < 50%

### 3.3 函数覆盖率
- **目标**: ≥ 90%
- **警告**: 70-90%
- **严重**: < 70%

### 3.4 关键路径覆盖
- **目标**: 100%
- **警告**: 90-100%
- **严重**: < 90%

## 4. 代码风格指标

### 4.1 ESLint 规则违规
- **目标**: 0 个错误
- **警告**: 1-5 个
- **严重**: > 5 个

### 4.2 Prettier 格式违规
- **目标**: 0 个违规
- **警告**: 1-10 个
- **严重**: > 10 个

### 4.3 注释覆盖率
- **目标**: 核心函数 100% 有注释
- **警告**: 80-100%
- **严重**: < 80%

## 5. 安全指标

### 5.1 安全漏洞
- **目标**: 0 个漏洞
- **警告**: 低危漏洞 1-3 个
- **严重**: 中危+ 漏洞存在

### 5.2 依赖安全问题
- **目标**: 0 个已知漏洞
- **警告**: 低危漏洞 1-5 个
- **严重**: 高危+ 漏洞存在

### 5.3 硬编码敏感信息
- **目标**: 0 处
- **警告**: -
- **严重**: 任何硬编码的密码/密钥/Token

## 6. 性能指标

### 6.1 数据库查询性能
- **目标**: 查询 < 100ms
- **警告**: 100-500ms
- **严重**: > 500ms

### 6.2 API 响应时间
- **目标**: p95 < 500ms
- **警告**: p95 500-1000ms
- **严重**: p95 > 1000ms

### 6.3 内存使用
- **目标**: 稳定，无持续增长
- **警告**: 轻微持续增长
- **严重**: 明显内存泄漏

## 7. 依赖指标

### 7.1 依赖更新状态
- **目标**: 所有依赖为最新稳定版
- **警告**: 有 1-3 个过时依赖
- **严重**: > 3 个过时依赖

### 7.2 未使用依赖
- **目标**: 0 个未使用依赖
- **警告**: 1-3 个未使用
- **严重**: > 3 个未使用

## 8. 文档指标

### 8.1 README 完整性
- **目标**: 包含所有必要章节
- **警告**: 缺少 1-2 个章节
- **严重**: 缺少 > 2 个章节

### 8.2 API 文档覆盖率
- **目标**: 100% API 有文档
- **警告**: 90-100%
- **严重**: < 90%

## 质量门禁标准

所有代码合并必须满足：

| 指标 | 必须满足 |
|------|---------|
| 圈复杂度 | ≤ 15 |
| 重复代码率 | < 5% |
| 行覆盖率 | ≥ 60% |
| 安全漏洞 | 0 个高危+ |
| ESLint 错误 | 0 个 |
| 硬编码敏感信息 | 0 处 |

## 持续监控

- 每次 PR 必须通过上述所有质量门禁
- 每周生成代码质量报告
- 每月分析质量趋势
- 每季度回顾并调整目标

## 工具支持

| 指标 | 工具 |
|------|------|
| 圈复杂度 | ESLint (complexity) |
| 测试覆盖 | Jest / Istanbul |
| 代码重复 | JSCPD |
| 代码风格 | ESLint + Prettier |
| 安全漏洞 | npm audit |
| 依赖检查 | npm outdated |
